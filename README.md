# Vermonster Skills

Shared AI skills for building healthcare technology software and digital health products.

## Skills

### `health-product-discovery`

Use this skill to shape healthcare product direction, workflow framing, stakeholder analysis, and early requirements before implementation.

### `health-fhir-api-design`

Use this skill to design interoperable healthcare APIs and data flows with FHIR-aware patterns and implementation trade-offs.

### `health-hipaa-secure-delivery`

Use this skill to inspect healthcare code and delivery systems for privacy and security gaps and produce a report-only HIPAA, PHI, and PII audit.

## Install

Install the full skill collection from this repository:

```bash
npx skills add https://github.com/reason-healthcare/health-skills/tree/dist
```
See also: [npx skill docs]()

For contributing and skill development, see [DEVELOPER.md](https://github.com/reason-healthcare/health-skills/DEVELOPER.md).
