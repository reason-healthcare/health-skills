# Repository Model

This repository is the source of truth for shared AI skills used to build healthcare technology software and digital health products.

## Canonical Source

Author skills in `skills/` only.

- `skills/.curated/`: reviewed skills intended for shared distribution
- `skills/.experimental/`: draft skills that are still being shaped

## Generated Install Trees

Treat these directories as generated install outputs for agent runtimes:

- `.claude/skills/`
- `.codex/skills/`
- `.gemini/skills/`
- `.github/skills/`

Do not hand-author base skill content in those directories. Compose them from canonical skills plus overlays.

## Preserved Authored Runtime Files

These runtime-specific files remain hand-authored and are not generated by the composition workflow:

- `.claude/commands/`
- `.gemini/commands/`
- `.github/prompts/`

## Overlay Contract

Optional overlays live under `profiles/<agent>/<skill>/`.

Supported overlay files:

- `SKILL.append.md`: appended to the base `SKILL.md`
- `agents/openai.yaml`: replaces the base `agents/openai.yaml` for that agent

Any other overlay paths are invalid until the validator and composer explicitly support them.

## Local Development Tooling

OpenSpec command files and OpenSpec runtime skills that live under agent-specific directories are local development tooling for this repository.

They are used to build and maintain the healthcare skill library, but they are not part of the canonical distributed skill source under `skills/`.

## Migration Rule

When migrating existing reusable skills:

- copy them into canonical source under `skills/`
- keep current runtime install trees in place until composed outputs are verified
- prefer non-destructive sync over directory removal
